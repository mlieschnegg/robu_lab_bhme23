# ROS-Code und Robotermodell

Hier entstehen die ROS-Packages einschließlich URDF/Xacro, Konfiguration und Launch-Dateien.
Die konkrete Package-Struktur wird bei der ROS-Einführung angelegt.
Noch kein ausführbarer Code enthalten. Start- und Testbefehle nach erfolgreicher
Erprobung dokumentieren; funktionierenden Stand im Roboterstatus vermerken.
