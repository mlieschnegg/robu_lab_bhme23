# Prüfungen

Hier wiederverwendbare Testabläufe, Messreihen und später automatisierte Tests ablegen.
Jeder Prüfablauf nennt Voraussetzungen, Durchführung, erwartetes Ergebnis und
Abbruchbedingungen. Tatsächliche Ergebnisse im Teamprotokoll festhalten.
Für reine Sicht- und Passproben genügt ein nachvollziehbarer manueller Nachweis.
